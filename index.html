Rubik's cube

Tourner le cube entier d'un quart de tour
Mouvements joués (0)
Solution (0 quarts de tour)

Les lettres désignent les faces telles qu'elles sont affichées (repères sur les centres).
Glisser horizontalement : rotation autour de l'axe vertical du cube ; verticalement : autour de l'axe passant par les faces latérales. Chaque changement d'orientation est noté x, y ou z. Double-clic pour revenir à la vue de départ.
Clavier : U L R D F B, avec Maj pour le sens inverse ; flèches pour tourner le cube d'un quart de tour ; Retour arrière pour annuler.
